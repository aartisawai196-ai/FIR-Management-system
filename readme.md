# FIR Management System

## 📌 Project Overview
The FIR Management System is a web-based application developed to manage First Information Reports (FIRs) digitally. It helps users register FIRs, report incidents, and track FIR details efficiently.

## 🚀 Features
- User Registration and Login
- Register a New FIR
- Report Incidents
- Track FIR Status
- Aadhaar-Based FIR Functionality
- Generate FIR PDF Reports
- Database Connectivity

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Backend:** Java Servlets
- **Frontend:** HTML, CSS, JavaScript
- **Database:** PostgreSQL
- **Database Connectivity:** JDBC
- **Build Tool:** Maven
- **Development Environment:** Eclipse IDE

## ⚙️ Prerequisites
- Java JDK
- Eclipse IDE
- Apache Tomcat Server
- PostgreSQL
- Maven

## ▶️ How to Run
1. Clone or download this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure the PostgreSQL database.
4. Update the database connection details in `DBConnection.java`.
5. Ensure the required database tables are created.
6. Configure Apache Tomcat in Eclipse.
7. Run the project on the Tomcat server.

## 🔐 Database Configuration
Update the database URL, username, and password according to your local PostgreSQL setup.

**Note:** Never upload real database passwords or other sensitive credentials to GitHub.
